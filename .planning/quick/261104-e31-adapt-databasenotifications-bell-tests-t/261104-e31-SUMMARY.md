# Quick task 261104-e31: Adapt bell tests to Filament lazy rendering

After the composer update, Filament's `DatabaseNotifications` Livewire component renders
notifications only while `isOpen` is true (it is set by the browser when the modal opens).
Tests that rendered the bell without opening it saw no notifications: the positive
assertions failed in CI (shards 2 and 3), and the negative leak assertions would have
passed vacuously.

Fix: the affected tests now call `->set('isOpen', true)` before `html()` / `assertSee()`.

Files: NotificationPreferencesTest, TimeLeakTest, DocumentFinanceLeakTest,
CardPaymentLeakTest, InvoiceLeakTest.

Verified: the five files pass in DDEV (86 tests).
