Decisions made in this plan (recorded):
- Classes live in a new `App\Domain\Api` area: `Models\IdempotencyKey`, `Idempotency\IdempotencyStore` (not `final`, so the concurrency test of plan 07-10 can bind a lock-less double, like `TimerLock` / `UnlockedTimerLock` in Phase 6), `Idempotency\IdempotencyClaim` and `Idempotency\IdempotencyOutcome`.
- The response body is stored as `text` (byte-identical replay); only status and body are replayed, not other headers (a replayed 201 carries no Location; documented).
- The stale-claim threshold is 120 seconds (research A7, surfaced: too short risks a duplicate after a slow request, too long keeps a crashed key at 409 for that time).
- Residual risk documented, not hidden: a crash after the entry commit but before the response is stored lets a stale takeover create a second entry; D-15 already makes the caller responsible for deduplication.
- The escape-hatch rule forbids raw table queries in `app/`, so every statement uses the Eloquent builder (`IdempotencyKey::query()->insertOrIgnore(...)` returns the inserted row count).
- The docs contract of this plan sits on the endpoint itself (the `#[Header]`, the endpoint description and the 409 / 422 examples on `store`).
