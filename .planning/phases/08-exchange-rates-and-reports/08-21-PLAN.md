UI-SPEC C3 (XLSX sheets, formats, header row, auto filter, widths, comment), B1 (the PDF item rendered only when a client is chosen; hidden, never disabled), Surface D (error toast), research Pitfall 1 and Pitfall 10 (the Livewire download holds the PDF in memory; accepted for freelancer volumes).

Decisions made in this plan (recorded):
- The summary sheet is accumulated while the entries stream, so the job reads the entries once; hours in "Souhrn" are numeric hours with the format `0.0000`, amounts numeric with `#,##0.00` and the currency in the next column.
- XLSX numbers are numeric cells built from integers and from the exact `Money::toMajor()` string converted only at the cell (a spreadsheet stores doubles anyway); the CSV keeps exact strings. Dates of "Záznamy" are date cells with a `d.m.yyyy` style format. Text cells stay `SpreadsheetCells::text()`.
- The PDF file name is built server-side from a fixed prefix per language (`pracovni-vykaz` / `work-report`) and the ISO period days; no user text in the name.

Fictional data only: names and canaries in tests are invented and built at runtime. Run `scripts/check-sensitive.sh` before every commit; never bypass the hook.
