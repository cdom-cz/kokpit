# Phase 08 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Scope: Phase 8 ships the money-and-time overview surfaces. All Admin surfaces are Admin only. The single Partner surface is the Partner dashboard, which shows no time, rates, prices, amounts or finance. Surfaces: A the CNB rates overview with its manual download and backfill; B the time report (filters, summary, expandable client > project > task tree, effective rate of fixed-price projects); C the export action and the exports list (CSV, XLSX); D the PDF work report document; E the Admin dashboard; F the Partner dashboard; G the System page "last rate date" slot and the CNB failure alert; H the export bell notifications.
>
> Nothing is built yet. Everything below is a target for plans, not a record of built work. Carried flags from earlier phases that touch this phase are restated under "Carried Flags".

## Spacing Scale

Inherited from 02, 05 and 06: declared values are multiples of 4, mapped to Filament's Tailwind 4 spacing (1 unit = 4px). Custom markup writes them in rem as 0.25, 0.5, 1, 1.5, 2, 3, 4.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Gap between a badge and its icon, gap between a stat label and value, gap between the two lines of a table cell (value and secondary line) |
| sm | 8px | Gap between filter controls, gap between icon and text in a tree toggle, gap between rows of the tomorrow plan list, gap between a Partner task row's lines |
| md | 16px | Padding of the summary tiles, padding of a Partner task row, gap between the filter strip and the summary, gap between a widget heading and its content, indent per tree level in the report (client 0, project 16px, task 32px, day or user 48px; Amendment A-1) |
| lg | 24px | Gap between the summary, the tree and the footnotes |
| xl | 32px | Page content horizontal padding, gap between page header and content (Filament stock) |
| 2xl | 48px | Not used |
| 3xl | 64px | Not used |

Component sizes that are not spacing tokens (all multiples of 4): report tree fixed table layout with a floor of 1024px (the wrapper scrolls, the page never does), Název column at least 320px, hour columns 96px, money columns 160px (Amendment A-1); tree toggle hit area at least 24 x 24px (WCAG 2.2 AA 2.5.8) with 8px to the next target; Partner task row left highlight border 4px; the Partner "Zkontrolovat úkol" button keeps Filament's stock small size.

Exceptions and rules:

- Everything inside Filament tables, forms, modals, stats and sections comes from stock components with stock spacing and no hand-written spacing.
- Custom markup (tree, plan block, Partner task list) uses only the tokens above. No 0.375rem, no 0.75rem, no fractional value (05 flag F-2 and the existing `day.blade.php` values `0.375rem` and `0.75rem` must not be copied).
- The PDF is a separate medium and declares its own point-based spacing in "Surface D".
- Dashboard grid: one column below `lg` (1024px), two columns from `lg`. Stats row: stock behaviour (stacked on a phone, three across from `md`).

## Typography

Inherited from 02, 05 and 06. Four sizes and two weights on screen; application code introduces no other.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (table cells, inputs, filter labels' helper text, notes, footnotes, plan block items, Partner task rows, secondary lines) | 14px (`text-sm`) | 400 regular | 1.43 (20px) |
| Label (field labels, button text, column titles, client and project rows in the tree, badge text, summary tile labels, stat labels) | 14px | 600 semibold | 1.43 (20px) |
| Heading (widget and section headings, summary tile group headings, modal and callout headings) | 16px (`text-base`) | 600 semibold | 1.5 (24px) |
| Display (page headings stock; the stat values of the hours stats and the summary tile values) | 24px below `sm`, 30px from `sm` up for page headings; stat and tile values fixed at 30px (`text-3xl`) | 600 semibold | 1.33 / 1.2 |

Contract notes:

- Declared sizes: 14, 16, 24, 30. Declared weights: 400, 600. No 12px, no weight 500 or 700 in application code (the existing `0.75rem` on the Signal day view is not copied).
- Secondary text (client name under a task, "Po termínu o 3 dny" line, notes, date descriptions) uses Filament's gray text colour at 14px, never a smaller size and never an opacity below 0.8.
- Money and durations: `tabular-nums`, right aligned in table columns. Durations use the single helper `DurationFormat::hoursMinutes()` (`H:MM`, truncated, sums formed from seconds first, see 06 Duration display). A running entry counts at its elapsed time at render.
- Money is formatted by `Money::format('cs')`: space as thousands separator (non-breaking), decimal comma, currency symbol after the amount (`12 000,00 Kč`, `480,00 €`). Amounts in the client currency and in CZK are never summed together; CZK is the only column that sums across clients.
- Dates: `j. n. Y` (existing `LocalisationServiceProvider::DATE_FORMAT`); times of day `H:i`; instants stored in UTC, shown in `Europe/Prague`; weekday names Czech. Empty values show `—`.
- Czech diacritics render in Inter on screen and in DejaVu Sans in the PDF. Check "Nevyfakturováno", "Částka v Kč", "Úkol", "Ke kontrole", "Čtvrtek" at the gate.
- CNB rates are shown with at least 3 and at most 10 decimals, trailing zeros beyond the third trimmed (`24,325`), never rounded for display.

## Access and Visibility Contract

Applies to every new class; the registry and canary tests enforce it (FND-18, RESEARCH Security).

- Every new Resource, Page and Widget declares `#[AccessRule(Audience::AdminOnly, reason)]` and uses the matching `Enforces*AccessRule` trait. The two Partner widgets (`PartnerTasks`, `PartnerProjects`) declare `Audience::PartnerAllowed` **and** override `canView()` to also require `PartnerContext::partnerClientId() !== null` and not Admin, like `PartnerProjectResource::canAccess()`. An Admin never sees a Partner widget and a Partner never sees an Admin widget.
- `Dashboard::getWidgets()` returns the Admin list for the Admin and the Partner list for a Partner. A widget list is never trusted alone: each widget's `canView()` and boot hook re-checks.
- The report page, exports and rates resources are closed to a Partner at boot (403), before anything is read. Report filters are URL state and Livewire properties and are **client-controlled**: ids are validated as UUIDs, the client and project must exist, dates go through `PragueDay::day()`, an invalid value falls back to the default, and the Admin check is repeated on every Livewire update.
- Export download: only through a Livewire row action that re-checks Admin, ownership (`ReportExport` is owned by the user) and expiry. No public URL, no signed URL, no new route.
- A Partner never receives time, rate, price, amount, currency or finance markup in HTML, Livewire snapshots, notifications, the bell, activity views or global search. The Partner dashboard queries use the pinned column builders (`ProjectColumns::partnerColumns()` / `TaskColumns::partnerColumns()`); no billing, estimate or time column is selected.
- The canary harness gets one `in_review` task and one time entry per client (exchange rates are not client data and need no canary). The route walk and a rendered-HTML check prove the Partner dashboard of client A contains none of client B's canary strings and none of the strings listed under "Never on a Partner surface" (Copywriting Contract).
- Hand-written SQL in the report reader is guarded by `PartnerContext` (Admin or system only), because raw joins bypass the Partner scope of the joined tables.

### Surface A: CNB rates overview `/admin/exchange-rates` — new (EX-01, EX-02, EX-03; D-02, D-04, D-05)

`ExchangeRateResource`, list page only, Admin only, group "Správa", sort 84. Heading "Kurzy ČNB".

- **Header stats** (`StatsOverviewWidget` registered on the list page, three stats, `$pollingInterval = '60s'`):
  1. "Poslední kurzy": the newest stored `rate_date` (`j. n. Y`); description "Staženo :datetime" from the newest `fetched_at`. When nothing is stored the value is `—` and the description "Kurzy ještě nebyly staženy".
  2. "Stav": the health result of the `last_rate_date` slot (label from `HealthStatus`, colour success, warning or danger, icon `OutlinedExclamationTriangle` for warning and danger); description is the same Czech detail as on the System page (Surface G). This is the page's text answer to "is the download working".
  3. "Měn v seznamu": the number of currencies in the newest list (about 30), description "Jednotka a kurz podle ČNB".
- **Header actions**, left to right: "Doplnit historii" (gray, `OutlinedCalendarDays`), "Stáhnout dnešní kurzy" (primary, `OutlinedArrowPath`).
- **Table**: one row per currency and date. Columns in order: Datum (`j. n. Y`, sortable), Měna (ISO code semibold, with the Czech currency name in gray after it, from ICU), Jednotka (`1`, `100`, `1000`), Kurz (CZK per Jednotka, `tabular-nums`, right aligned, trimmed as in Typography), Staženo (`j. n. Y H:i`, toggleable and hidden by default). Default sort: Datum descending, then Měna ascending. 30 rows per page, options 30, 60, 120.
- **Filters** (AND): "Datum" (`DatePicker`, **default = the newest stored date**, so the page opens on the current list; clearing it shows all days), "Měna" (select of stored currency codes). The active Datum is shown as an indicator chip. A Datum without a list (weekend, holiday) shows the empty state "Pro tento den ČNB kurzy nevyhlásila" with the body "Platí poslední vyhlášené kurzy ze dne :date." (the date resolved by the lookup).
- **"Stáhnout dnešní kurzy"** runs the same synchronous action as the scheduler (one request, 15 s timeout). Outcomes as toasts: new list stored (success), list for today already stored (info), CNB has no newer list yet (info), failure (danger); texts in the Copywriting Contract. The button shows Filament's stock in-flight state.
- **"Doplnit historii"** opens a modal "Doplnit historii kurzů": `DatePicker` Od (required), `DatePicker` Do (required, default today), helper "Víkendy a svátky se stahovat nemusí, platí pro ně poslední vyhlášený kurz." Submit "Doplnit historii" (primary), cancel "Nedoplňovat" (`modalCancelActionLabel`). The submit queues `BackfillCnbRates` and shows an info toast; the page does not wait. Validation (field errors under the offending field): Od later than Do; Od before 1. 1. 2000; Do in the future; span above the configured maximum. A rerun over the same range is allowed and creates nothing new (idempotent), the toast is the same.
- **Empty (no rates ever stored):** heading "Zatím tu nejsou žádné kurzy", body "Stáhněte první seznam tlačítkem Stáhnout dnešní kurzy. Kurzy se pak stahují samy každý pracovní den odpoledne.", the header action stays reachable.
- No create, edit, delete or bulk action exists: CNB lists are immutable once stored.

### Surface B: Time report `/admin/time-report` — new (RE-01, RE-02, RE-05; D-06, D-07, D-08)

`TimeReportPage`, Admin only, no navigation group, sort 42. Heading "Report času". The page is a custom Blade view assembled from a filter strip, a summary, the tree and footnotes.

**B1. Filter strip** (a `GET` form like the timesheet: `x-on:change="$el.requestSubmit()"` submits on every change, so the strip has no submit button and the report page has no accent button of its own). State in the URL: `?client=<uuid>&project=<uuid>&period=this_month|last_month|custom&from=YYYY-MM-DD&to=YYYY-MM-DD&split=none|day|user`. Defaults: all clients, all projects, `this_month`, `none`. Anything invalid falls back to the default.

- "Klient": native `x-filament::input.select`, first option "Všichni klienti", archived clients included (the report covers past work) and marked "(archivovaný)".
- "Projekt": native select, first option "Všechny projekty", limited to the chosen client's projects; disabled with the placeholder "Nejdřív vyberte klienta" until a client is chosen.
- "Období": a segmented group of three `x-filament::button` links "Tento měsíc", "Minulý měsíc", "Vlastní" (`aria-current` on the active one, `primary` colour when active, gray otherwise, like the timesheet view switch). "Vlastní" reveals two `type="date"` inputs "Od" and "Do" (required, Od not after Do; an invalid pair falls back to this month and shows the danger line "Datum Od nesmí být později než Do."). The active range is always printed as text next to the group: "1. 10. 2026 – 31. 10. 2026".
- "Rozpad": a segmented group "Bez rozpadu", "Po dnech", "Podle uživatelů" (`aria-current`, same styling). It adds child rows below each task (see B3).
- Header action: a single `ActionGroup` trigger "Exportovat report" (gray, `OutlinedArrowDownTray`) with items "Tabulka CSV", "Tabulka XLSX" (both queue `BuildReportExport` with the current filters, Surface C) and "Pracovní výkaz PDF" (generates and downloads the PDF, Surface D). The PDF item is rendered **only when a client is chosen**; it never appears disabled. A link "Exporty" (gray, `OutlinedArrowDownTray`) to Surface C sits next to the group.

**B2. Summary** (four tiles in a grid, one column on a phone, two from `sm`, four from `lg`; each tile an `x-filament::section` with a 16px/600 heading, a 30px/600 value and up to two gray 14px lines). Computed over the **whole filtered set**, never over the rendered rows:

1. "Odpracováno": `H:MM`; lines "Fakturovatelné :duration" and "Nefakturovatelné :duration".
2. "Nevyfakturováno": billable unbilled `H:MM` as the value; lines the amount per client currency (one line per currency, for example `12 000,00 Kč` and `480,00 €`) and "v Kč: :czk". `info` colour on the heading's badge.
