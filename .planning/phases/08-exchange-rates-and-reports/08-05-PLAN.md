Decisions made in this plan (recorded):
- `ReportExport` uses `OwnedByUser` (Admin-only plus the owner scope): even a second Admin reads only the own exports.
- `label` is a server-built description (client and project names, the period) shown in the list and carrying the canary; `filters` holds only validated ids and Prague days; no user text ever reaches `path` or the download name.
- `path` is `report-exports/<export uuid>.<csv|xlsx>` on the default (private) disk, pinned by a CHECK; the download name is built from the period only (`report-casu-<from>-<to>.<ext>`).
- `user_id` references `users` with the default NO ACTION (users are deactivated, never deleted; the 7-day expiry keeps the table small).
- No delete action in the list: the prune job of plan 08-13 removes expired rows and files.

Fictional data only. Run `scripts/check-sensitive.sh` before every commit; never bypass the hook.
