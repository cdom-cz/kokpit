Decisions made in this plan (recorded):
- Text cells are explicit OpenSpout string cells after the apostrophe prefix; the value-inferring row factory of OpenSpout is never fed user text, and a self-check test proves the canary would catch it.
- Numbers in the CSV are written as text in the configured decimal format: seconds as an integer, hours from integer arithmetic to four decimals (half up), amounts from `Money::toMajor()` with the decimal sign swapped (two decimals for two-digit currencies), never floats.
- The job reads the record in the system context, skips a record that is not pending, writes to a temporary file, streams it to `ReportExport::storagePath()` on the default (private) disk, then marks the record ready and notifies the owner with `notifyNow` in one transaction (pattern of `NotifyLongRunningTimers`). `failed()` marks the record failed and sends the failed bell inside an explicit system run (the job middleware does not wrap `failed()`); the Phase 3 failed-job alert also fires.
- The `summary` ("Zadání") is built by the page action from the selected client and project names (or "Všichni klienti" / "Všechny projekty") and the period text; the bell bodies name only the format and the period (UI-SPEC H).
- The menu is a gray `ActionGroup` "Exportovat report" with the arrow-down-tray icon; this plan adds the "Tabulka CSV" item, plan 08-21 the "Tabulka XLSX" and "Pracovní výkaz PDF" items.

Fictional data only: names in tests are invented and formula canaries are built at runtime. Run `scripts/check-sensitive.sh` before every commit; never bypass the hook.
