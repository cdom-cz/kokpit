# Phase 09.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Pest 5.3.2 on PHPUnit 13 |
| **Config file** | `phpunit.xml`, `tests/Pest.php` |
| **Quick run command** | `ddev exec vendor/bin/pest tests/Feature/Api tests/Feature/Finance tests/Isolation/ApiAccessTest.php` |
| **Full suite command** | `ddev exec vendor/bin/pest` |
| **Static analysis** | `ddev exec vendor/bin/phpstan analyse --no-progress --memory-limit=1G` |
| **Style** | `ddev exec vendor/bin/pint --test` |
| **Estimated runtime** | quick ~30 s, full suite several minutes |

---

## Sampling Rate

- **After every task commit:** the single test file of the task, plus `ddev exec vendor/bin/pest tests/Isolation/ApiAccessTest.php` whenever routes or abilities change
- **After every plan wave:** `ddev exec vendor/bin/pest tests/Feature/Api tests/Feature/Finance tests/Feature/Schema tests/Isolation`, then phpstan and pint
- **Before `/gsd-verify-work`:** full suite green, phpstan, `pint --test`, `scripts/check-sensitive.sh`, `ddev exec php artisan scribe:generate`. No `--parallel` for the docs tests.
- **Max feedback latency:** ~60 seconds per task
