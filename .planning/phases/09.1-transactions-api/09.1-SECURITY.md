# Phase 09.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Action data -> TransactionInput | rate, unit amount, currency and CZK figure are caller-controlled | finance amounts, rates |
| TransactionCzk -> transactions row | stored figure and snapshot must satisfy the CHECKs | finance amounts |
| HTTP client -> /api/v1 finance routes | bearer token and path are untrusted | token, finance data |
| Admin token -> finance data | only a token carrying the finance ability may read finance data | abilities |
| generated docs / CONTRIBUTING -> public repository | text is public | documentation |
| Admin -> token screen / Partner session -> Admin pages | Admin picks abilities; Partner must see nothing | token abilities |
| Admin form state -> Filament closures | Livewire state is client-controlled; the Action re-validates | form state |
| HTTP client -> list query string | filter values, sort and cursor are untrusted | query parameters |
| HTTP client -> write body / batch envelope | every field and unknown key is untrusted | transaction payload |
| finance Actions -> PostgreSQL | CHECKs and composite FKs are the last guard | rows |
| Idempotency-Key -> api_idempotency_keys | key bound to token and body hash | stored responses |
| API client -> PATCH/POST (09.1-09) | null keys and JSON types of integer fields are client-controlled | payload types |

### Residual risks noted by the audit (inside closed threats, non-blocking)

- **WR-02 (T-09.1-18/19):** a batch running longer than `idempotency_stale_lock_seconds` (120 s) could be taken over by a retry with the same key and saved twice. Local measurement is under 1 s; production `max_execution_time` and proxy timeouts remain an owner open item. Tracked as `open` in `09.1-REVIEW-DISPOSITION.md`.
- **WR-03 (T-09.1-16, informational):** a row deleted between `find()` and `lockForUpdate()->firstOrFail()` yields Laravel's default 404 body naming the model class; a concurrent PATCH race may act on an outdated snapshot. Low impact. Tracked as `open` in `09.1-REVIEW-DISPOSITION.md`.
