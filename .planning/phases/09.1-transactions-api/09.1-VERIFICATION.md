## What Changed Since the Previous Report

`git diff 6ca457d..HEAD` (the last 09.1 code commit) on the covered implementation files shows three later contributions to the Transactions API surface. None weakens a 09.1 truth.

| Later change | Commits | Effect on phase 09.1 |
| ------------ | ------- | -------------------- |
| `external` free-form object on create, batch item and PATCH (absent keeps, null clears, object replaces whole); `ExternalObject`, `RawJsonBody`, migration `2026_10_18_000900` | f51fd24, d58074a, 8dc3ebb (quick-261018-mic) | Additive. `TransactionPayload::external()` forwards the key only when the body names it; `RecordTransaction::write()` and `UpdateTransaction::handle()` parse it before any write. CZK figure rules (CR-01 path) untouched. |
| Income of an invoice payment is locked: PATCH may change only `transaction_date` and `category_id`, DELETE is refused | 268f47f, 61bdbfc (10-16, 10-19) | Both refusals are **422 ValidationException** (`payment_transaction_locked` under each changed key, `payment_transaction_delete` under `transaction`), raised in the Actions on the locked row. They pass through `TransactionPayload::remap()` for PATCH and propagate as the standard 422 from DELETE. This is the 09.1-08 hand-over; `TransactionController::CONFLICT_METHODS` correctly stays `['DELETE']` because the refusal did not become a 409. |
| `RecordTransaction::writePaymentIncome()` (no Gate, requires an invoice link) | 60593bc (11-02) | Not reachable from any API route; the API calls `handle()` only, which passes `$invoiceLink = null`. `invoice_id` and `invoice_payment_id` are never read from request data (written with `forceFill` from the typed link only). |

Note on the review request: the "409 `entry_locked`" mentioned in the task belongs to the **time entry** endpoints (`TimeEntryController`, `ApiExamples::ENTRY_LOCKED`), not to transactions. For transactions the locked-payment-income answer is 422, as above; the only transaction 409s are `transaction_in_use` (DELETE) and `idempotency_in_progress` (creates).
