## Pattern Assignments

### `routes/api.php` (route, request-response)

**Analog:** same file. Add two groups after the time groups; one `abilities:` per group, matching throttle, never mix time and finance routes.

**Imports to add** (after l.6-10): `TransactionBatchController`, `TransactionCategoryController`, `TransactionController`.

**Group shape** (lines 21, 46-65):
```php
Route::middleware(['auth:sanctum', 'abilities:'.ApiAbility::TimeRead->value, 'throttle:api-read'])->group(function (): void {
    Route::get('time-entries/{timeEntry}', [TimeEntryController::class, 'show'])
        ->whereUuid('timeEntry')
        ->name('api.v1.time-entries.show');
});
Route::middleware(['auth:sanctum', 'abilities:'.ApiAbility::TimeWrite->value, 'throttle:api-write'])->group(function (): void {
    Route::post('time-entries', [TimeEntryController::class, 'store'])
        ->middleware(EnsureIdempotency::class)
        ->name('api.v1.time-entries.store');
    // Declared before PATCH/DELETE; the path has no parameter, so it never clashes.
    Route::post('time-entries/batch', TimeEntryBatchController::class)
        ->middleware(EnsureIdempotency::class)
        ->name('api.v1.time-entries.batch');
    Route::patch('time-entries/{timeEntry}', [TimeEntryController::class, 'update'])->whereUuid('timeEntry')->name('api.v1.time-entries.update');
    Route::delete('time-entries/{timeEntry}', [TimeEntryController::class, 'destroy'])->whereUuid('timeEntry')->name('api.v1.time-entries.destroy');
});
```
Use the concrete route block from RESEARCH.md Pattern 1 (FinanceRead/FinanceWrite). Category show route: lookups (clients/projects) do NOT use `whereUuid` (the resolver answers the Czech 404), but transactions and categories take UUIDs only, so `whereUuid` as in time entries is correct.

### `app/Http/Controllers/Api/V1/TransactionController.php` (controller, CRUD + cursor list)

**Analog:** `app/Http/Controllers/Api/V1/TimeEntryController.php`

**Class attributes and constants** (l.48-68):

```php
    public const array SORTS = ['started_at', 'created_at'];
    public const string ID_COLUMN = 'time_entries.id';
```
For transactions: `FILTERS = ['type','category','client','project','date_from','date_to','currency','czk_source']`, `ID_COLUMN = 'transactions.id'`, plus a `SORT_COLUMNS` map (`amount` -> `czk_minor`) because the cursor keys must be the internal column (RESEARCH Pattern 3). `ApiDocs::violations()` reads `FILTERS`/`SORTS` and demands a `#[QueryParam]` for each, plus `cursor`, `per_page`, `sort`.

**List pattern** (l.86-121): `QueryBuilder::for(...)->allowedFilters(AllowedFilter::callback(...))->allowedSorts(...)->defaultSort('-started_at')->orderBy(self::ID_COLUMN, $descending ? 'desc' : 'asc')->cursorPaginate($request->perPage())->withQueryString()`, returned via `Resource::collection($page)`. Project filter resolves via `$refs->projectId()` and falls back to `whereRaw('false')` (l.94-98). Full adapted filter set: RESEARCH.md "Reading the filter set into the query".

**Show / find / actor** (l.147-149, 264-287):
```php
private static function find(string $id): TimeEntry
{
    $entry = TimeEntry::query()->with(['project', 'task'])->whereKey($id)->first();
    if ($entry === null) { abort(404, __('api.errors.not_found')); }
    return $entry;
}
private static function actor(Request $request): User
{
    $user = $request->user();
    if (! $user instanceof User) { abort(401); }
    return $user;
}
```
No implicit model binding (route params are plain strings).

**Create** (l.177-186): action call, `201`, `Location` header:
```php
return (new TimeEntryResource($entry))->response()->setStatusCode(201)
    ->header('Location', route('api.v1.time-entries.show', $entry->id));
```
Wrap `RecordTransaction::handle()` in `try { } catch (ValidationException $e) { throw TransactionPayload::remap($e); }` (error keys `amount`->`amount_minor`, `czk_amount`->`czk_amount_minor`).

**Update** (l.213-233): `forUpdate($validated, $entry, ...)` only with keys the body named; `ApiError::conflict(code, $e->getMessage())` for locked. For transactions map `DeleteTransaction` `RuntimeException` to `ApiError::conflict('transaction_in_use', ...)` (RESEARCH Open Question 1).

**Delete** (l.244-259): `response()->noContent()`; return type `JsonResponse|HttpResponse`.

**Scribe docs per endpoint:** `#[Endpoint(title, 'Requires ability `finance:read` ...')]` (ability string in backticks is enforced), `#[UrlParam]`, `#[Header('Idempotency-Key', 'demo-key-0001')]` on create, `#[Response(...)]` for 200/201/404/409/422 (PATCH needs `[200,404,409,422]`, DELETE `[204,404,409]`), `#[ResponseField('data.x', ...)]` per field.

### `app/Http/Controllers/Api/V1/TransactionBatchController.php` (controller, partial-success batch)

**Analog:** `app/Http/Controllers/Api/V1/TimeEntryBatchController.php` (copy nearly verbatim; rename `entries`->`transactions`, `entry`->`transaction`).

**Core loop** (l.70-106):
```php
$actor = self::actor($request);
$items = $request->validated('entries');
$raw = TimeEntryPayload::rawBody($request)->entries ?? [];
$saved = 0; $errors = [];
foreach (is_array($items) ? array_values($items) : [] as $index => $item) {
    try {
        $create->handle($actor, TimeEntryPayload::forBatchItem($item, $raw[$index] ?? null, $refs));
        $saved++;
    } catch (ValidationException $e) {
        $errors[] = ['index' => $index, 'errors' => $e->errors()];
    } catch (Throwable $e) {
        report($e);
        $errors[] = ['index' => $index, 'errors' => ['entry' => [__('api.errors.batch_item_failed')]]];
    }
}
$counts = ['saved' => $saved, 'failed' => count($errors), 'errors' => $errors];
if ($errors === []) { return new JsonResponse($counts, 201); }
if ($saved > 0) { return new JsonResponse($counts, 207); }
return new JsonResponse(['message' => __('api.errors.batch_none_saved'), ...$counts], 422);
```
No outer DB transaction (docblock l.24-31 explains: idempotency key release + double save). Transactions have no `raw` object need (no `external`), so `forBatchItem` can drop the `$rawItem` parameter; still reject non-array items with `ValidationException::withMessages(['transaction' => __('api.errors.batch_item_not_object')])`. Apply `TransactionPayload::remap()` in the ValidationException catch. Docs: `#[BodyParam('transactions[].x', ...)]` lines, `#[Response(ApiExamples::BATCH_ALL_SAVED|BATCH_MIXED|BATCH_NONE_SAVED, ...)]`; batch limit 500 text in description.

## Shared Patterns

### Token auth + ability + throttle
**Source:** `routes/api.php` l.21, 46. **Apply to:** all finance routes. One `abilities:` per group; `ApiAccessTest` route walk fails otherwise (its `$limits` map must gain both finance abilities).

### Idempotency
**Source:** `routes/api.php` l.50-58 (`->middleware(EnsureIdempotency::class)`). **Apply to:** `POST transactions` and `POST transactions/batch` only. Docs need `#[Header('Idempotency-Key', ...)]`, 409 `idempotency_in_progress` and 422 `idempotency_key_reused` responses.

### Admin-only enforcement
**Source:** `RecordTransaction::handle` `Gate::forUser($actor)->authorize('create', Transaction::class)` (l.38). **Apply to:** every write; controllers add no own checks. `actor()` helper copied from `TimeEntryController` l.278-287.

### Error shape and 404
**Source:** `abort(404, __('api.errors.not_found'))`, `ApiError::conflict(code, message)`, Laravel 422 `ValidationException` with Czech messages from `finance.transactions.errors.*`. Remap Action keys to API field names in one place (`TransactionPayload::remap`).

### Scribe example constants
**Source:** `ApiExamples.php`, `LookupExamples.php` (fixed constants, no DB/response calls, fictional values only). **Apply to:** all new endpoints via `TransactionExamples.php`.

### Cursor pagination
**Source:** `ApiCursor::rule()` plus `->orderBy(ID_COLUMN, dir)->cursorPaginate($request->perPage())->withQueryString()`. **Apply to:** both new list endpoints.
