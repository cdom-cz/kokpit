- R-19-04-2 (StaleArticle): constructor `(public readonly int $currentVersion, public readonly bool $redactionChanged = false)`, same fixed message; no content.
- R-19-04-3 (classification input): `final readonly class ArticleClassification` with a private constructor over `public ?string $folderId`, `public ?string $clientId`, `public ?string $projectId`, `public array $tags` (`list<string>`), constants `MAX_TAGS = 20`, `MAX_TAG_LENGTH = 40`, and `public static function from(mixed $folderId, mixed $clientId, mixed $projectId, mixed $tags): self`: null, '' or a non-string id becomes null; a string id that is not a UUID (`Str::isUuid`) is a ValidationException on `folder_id` (`knowledge.links.errors.folder_missing`), `client_id` (`client_missing`) or `project_id` (`project_mismatch`); a project without a client is a ValidationException on `project_id` with `knowledge.links.project_needs_client`; tags: a non-array is [], every entry must be a string, a NUL byte is a ValidationException on `tags` with `knowledge.errors.nul_character`, entries are trimmed, empty ones dropped, one over MAX_TAG_LENGTH (mb_strlen) is `knowledge.tags.errors.too_long` with max, duplicates are removed case-insensitively (mb_strtolower) keeping the first spelling, more than MAX_TAGS left is `knowledge.tags.errors.too_many` with max. No Filament type. `ArticleInput` gains `public ?ArticleClassification $classification` and `from(mixed $title, mixed $body, mixed $sensitive, mixed $clearSensitive = false, ?ArticleClassification $classification = null)`; null means "keep the stored classification" (RestoreVersion, the concurrency worker, API callers).
