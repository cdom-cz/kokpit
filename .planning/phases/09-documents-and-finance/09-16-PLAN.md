Decisions made in this plan (recorded):
- Totals include files of archived owners (D-21, decision at plan check): archiving deletes nothing, so those objects still occupy the bucket and the totals describe storage, not the default listing. The tiles carry the description `documents.totals.includes_archived`, and an archived client's row in the by-client table shows the `documents.totals.archived_client` label next to its name (copy written by plan 09-14).
- The D-11 "Unattached" row is labelled "Nepřiřazené ke klientovi" (`documents.totals.no_client`, written by plan 09-14) because it also holds receipts of transactions without a client (research A17); the owner can rename it in the copy.
- Totals ignore the listing filters (they describe the whole storage); this plan does not edit `lang/cs/documents.php` (09-17 edits it in the same wave).
- Widgets live under `app/Filament/Resources/DocumentResource/Widgets` and are registered in `DocumentResource::getWidgets()` and `ListDocuments::getHeaderWidgets()` (pattern of `ExchangeRateStats`).
