Decisions carried in (locked): D-15 (two levels, type per category, child inherits, archive but not delete once used, unused deletable, manual order with eloquent-sortable), D-16 (system income category renameable, not deletable or archivable).

Decisions made in this plan (recorded):
- Manual order is "move up" and "move down" row actions over `SortableTrait::moveOrderUp()` / `moveOrderDown()` within the sibling group, not Filament's reorder mode, because the list shows a tree order that Filament's reorder mode would flatten.
- Create and edit are modal actions on the list page, so the resource has no record routes (the route walk needs no entry).
- Delete relies on the database: the Action deletes inside a savepoint and translates SQLSTATE 23503 (children now, transactions from plan 09-09 on) into `finance.categories.errors.in_use` and KP001 into `finance.categories.errors.system_locked`; a pre-check gives the same messages without a round trip.
- Translations of the finance module live in a new `lang/cs/finance.php` (precedent `lang/cs/work_report.php`). This plan also writes the `transactions.errors.*` contract for plan 09-22 (`TransactionInput`, `TransactionCzk`), so 09-22 does not edit the file.
- Navigation: "Kategorie" with `navigationSort` 62 (Transactions 60, Finance overview 61).
