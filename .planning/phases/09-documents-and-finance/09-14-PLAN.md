Decisions made in this plan (recorded):
- File-type groups (Claude's discretion): images (`image/*`), PDF (`application/pdf`), text and office documents (extensions doc, docx, odt, rtf, txt, md), spreadsheets (xls, xlsx, ods, csv), presentations (ppt, pptx, odp), archives (zip, 7z, rar, tar, gz), other (everything else).
- The date filter works on `created_at` with inclusive Prague days through `PragueDay`; the client filter offers archived clients too (Admin view).
- `DocumentActions::bulkActions()` returns the listing's bulk actions so plan 09-17 adds the ZIP action there without editing `DocumentResource` (09-16 edits the resource in the same wave).
- This plan writes the totals copy (`documents.totals.*`, including the D-21 label keys `includes_archived` and `archived_client`) that plan 09-16 reads, so 09-16 does not edit `lang/cs/documents.php`.
- Archived owners (D-21): a `TernaryFilter` `archived_owners` with `default(false)`; false (the default) applies `Document::withoutArchivedOwners()`, true applies `onlyArchivedOwners()`, the blank option shows every file. The rule itself lives in the scopes of plan 09-21, not in the resource. The owner column keeps showing an archived owner's name and link.
- The listing has only the `index` page (no record routes); navigation "Soubory", `navigationSort` 55.
