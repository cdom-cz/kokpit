- Archived tasks offer no start (the Action refuses them anyway, plan 06-02).
- One query per render finds the signed-in user's running task id for the list and the board; no per-row query.

Fictional data only. Run `scripts/check-sensitive.sh` before every commit; never bypass the hook.
