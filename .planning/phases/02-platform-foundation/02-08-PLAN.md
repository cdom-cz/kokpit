<objective>
Make every user-facing string Czech and every displayed date, number and amount Czech-formatted in the `Europe/Prague` time zone, while storage stays UTC: laravel-lang strings in `lang/cs`, Filament's own Czech packs, format defaults set once in a provider, and tests for the edges that silently go wrong (day boundary, both DST switches, Unicode normalisation, no English fallback on screens the app uses).

Purpose: FND-11 and the display half of FND-03. Localisation infrastructure comes before roles and install (02-09), so every later string lands in `lang/cs` and every later enum is caught by the enum label check.
Output: `lang/cs` files, `config/app.php` defaults, `LocalisationServiceProvider`, four localisation test files and a reusable enum label checker.
</objective>
