<objective>
Create the two roles through the permission package, an install command that creates the single Admin without any default or argument password, and mandatory Admin TOTP from the first login using Filament's built-in multi-factor authentication with recovery codes, switchable off only outside production, plus a server-side reset for a lost device.

Purpose: FND-17 and the role half of FND-06 (the default-deny data layer follows in 02-10). Filament evaluates `isRequired` for multi-factor authentication once at route registration, so Admin-only enforcement needs a custom middleware, not a closure (RESEARCH Pattern 7).
Output: `RoleName`, `RoleSeeder`, `kokpit:install`, `kokpit:admin:reset-2fa`, `EnsureAdminHasTwoFactor`, `ProductionConfigGuard`, panel MFA wiring, Czech strings and four test files.
</objective>
