<objective>
Establish the data conventions on the tables that exist so far and prove them with a catalogue-driven schema test: UUID v7 keys (with a PostgreSQL `uuidv7()` safety net), `timestamptz` everywhere, an enforced morph map, and the Spatie permission tables converted to UUIDs through edited published migrations plus registered `HasUuids` subclasses.

Purpose: FND-02 and FND-03 storage half. RESEARCH Pattern 1 shows that a package model used without a `HasUuids` subclass silently corrupts keys (the id becomes the integer 1), so subclass-and-register is mandatory and the schema test is the real guard. The test reads `pg_catalog`, so tables added later (02-04 and every later phase) are checked without anyone listing them.
Output: edited skeleton and permission migrations, `User` moved to `App\Domain\Identity\Models`, `Role`/`Permission` subclasses, `KokpitModel`, `MorphMap`, `ModelConventionsServiceProvider`, `PgSchema` helper and three schema test files.
</objective>
