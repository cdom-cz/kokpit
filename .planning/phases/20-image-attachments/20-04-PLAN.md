Rulings made in this plan (recorded):
- R-20-04-1 (`ImageReferences`, final, static, in `Support/`): `SCHEME = 'kokpit-attachment:'`; `in(string $markdown): list<string>` returns every uuid that follows the scheme anywhere in the text (regex `kokpit-attachment:` followed by an 8-4-4-4-12 hex uuid, case-insensitive hex), lowercased, unique, in first-occurrence order. It is deliberately a superset of what the renderer shows (it also matches inside code blocks and links): a false "referenced" only keeps an image longer, a false "unreferenced" would delete a visible one; the docblock says so. `idFromUrl(string $url): ?string` returns the lowercased uuid only when the whole URL is exactly the scheme plus a uuid. `markdown(string $id, string $alt): string` returns `![` alt `](kokpit-attachment:` id `)`; the caller passes an alt text already sanitised by 20-05.
- R-20-04-2 (`ImageContext`, final readonly, `Support/`): private constructor over `array<string, array{src: string, width: int, height: int}>` keyed by lowercase uuid; `none(): self`; `of(array $images): self` lowercases the keys and throws InvalidArgumentException for a src that does not match `InternalImageSrcSanitizer::PATTERN` or a width or height below 1; `find(string $id): ?array`; `ids(): list<string>`. It holds no model and calls no helper.
- R-20-04-3 (`InternalImageSrcSanitizer`, final, implements Symfony `AttributeSanitizerInterface`): `PATTERN = '#^/admin/knowledge/attachments/[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$#'` (the panel path `admin` plus the route of 20-07; 20-07 tests that the real route path matches it); supported element `img`, attribute `src`; returns the value when it matches, otherwise null. The sanitiser chain applies every matching attribute sanitiser and stops on null (research Pattern 8), so the URL sanitiser can never re-admit what this one dropped.
- R-20-04-4 (missing image) `MissingImage extends League\CommonMark\Node\Inline\AbstractInline` holding the alt text (constructor argument, `alt(): string`); `MissingImageRenderer` (constructor takes the `$translate` closure like `TaskListMarkerRenderer`) returns `<span class="kokpit-image-missing">` with the escaped alt text, or the escaped `image.missing` translation when the alt is empty. A missing image is never emitted as `HtmlInline` (escaped by `html_input => 'escape'`, research Pattern 8).
- R-20-04-5 (`LinkAndImagePolicy`): new `useImages(ImageContext $images): void`; the default context is `ImageContext::none()`. For each Image node: `ImageReferences::idFromUrl($image->getUrl())`; when it is a uuid present in the context, `setUrl($entry['src'])` and `$image->data->set('attributes', ['width' => (string) $entry['width'], 'height' => (string) $entry['height'], 'loading' => 'lazy', 'decoding' => 'async'])`; when it is a uuid absent from the context, replace the node with `new MissingImage($alt)`; any other URL keeps the Phase 18 behaviour (replaced by its alt text as a Text node).
