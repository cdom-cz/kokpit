## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| any browser -> GET /admin/knowledge/attachments/{uuid} | the uuid is guessable only with difficulty but must never be the only key |
| application -> private bucket | the bucket is never exposed; bytes are streamed |
| image response -> browser | the response is rendered by the browser from the application origin |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-20-22 | Information disclosure | IDOR on the image route by a Partner or a guest | high | mitigate | panel authentication first (guest redirect), Partner 403 before any lookup, policy of the owning article, pending only for the uploader; Feature tests, route walk and channel probe |
| T-20-23 | Information disclosure | bucket or presigned URL reaching the browser | high | mitigate | bytes streamed through `$disk->response()`; no redirect and no Location header (test); the controller calls no URL method of the disk |
| T-20-24 | Elevation of privilege | stored image rendered as active content from the app origin | medium | mitigate | Content-Type from the stored (re-encoded) type, nosniff, `default-src 'none'; sandbox` CSP and inline disposition on this response only |
| T-20-25 | Information disclosure | stale or copied link reused after logout | high | mitigate | no signed URL; every request needs a live session; logout test (D-11) |
| T-20-26 | Information disclosure | 304 revealing that an image exists to an unauthorised caller | medium | mitigate | the ETag comparison runs only after step 4 of the check order; tests with If-None-Match as guest and Partner |
| T-20-27 | Denial of service | request flood on the image route | low | mitigate | `throttle:knowledge-attachments`, per user, configurable (test with a limit of 3) |
