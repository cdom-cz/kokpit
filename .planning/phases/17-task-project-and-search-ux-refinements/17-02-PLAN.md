Rulings made in this plan (recorded):
- R-17-02-1 (image predicate): `DocumentDisposition::isInlineImage(Document $document): bool` returns `self::isInline($document) && str_starts_with($document->mime_type, 'image/')`, so exactly PNG, JPEG, GIF and WebP (the image part of `INLINE_MIME_TYPES`); SVG is not on the allowlist and never qualifies; `mime_type` is the type detected from the bytes at upload. Docblock names D-08.
- R-17-02-2 (lightbox, D-08): `DocumentActions::preview()` keeps its name `preview`, label `documents.actions.preview`, icon and visibility (`DocumentDisposition::isInline`). For an image row it is a modal: `->modalHeading(static fn (Document $record): Htmlable => new HtmlString('<span style="display:block;overflow:hidden;text-overflow:ellipsis;white-space:nowrap;">'.e($record->name).'</span>'))`, `->modalWidth(Width::FiveExtraLarge)`, `->modalSubmitAction(false)`, `->modalCancelActionLabel(__('documents.actions.close'))`, and `->modalContent(static function (Document $record): View { ... })` that first runs `Gate::forUser(self::user())->authorize('view', $record)` and `abort_unless(DocumentDisposition::isInlineImage($record), 404)`, then returns `view('filament.documents.lightbox', ['src' => DocumentUrl::preview($record, self::user()), 'name' => $record->name])`. The image link is minted when the modal renders, never in the row. The old redirecting `->action()` closure of preview is removed: an image has no submit and a PDF has a URL (R-17-02-3). ESC, the close X and a backdrop click close the modal (Filament defaults); there is no previous/next, zoom or thumbnail strip.
- R-17-02-3 (PDF in a new tab, owner decision "Signed PDF link exception" recorded in 17-CONTEXT.md Plan-phase Clarifications on 2026-10-29): `preview()` gains `->url(static fn (Document $record): ?string => DocumentDisposition::isInlineImage($record) ? null : DocumentUrl::preview($record, self::user()), shouldOpenInNewTab: true)`; for a non-image inline row Filament renders an `<a href target="_blank">` (the URL is minted when the row renders), for an image row the URL is null and the modal of R-17-02-2 applies. The link's safety stays with the route, unchanged: authenticated panel route, `signed`, `u` must equal the signed-in user, the Partner-scoped lookup, the `view` policy, `nosniff` and the no-referrer header (DocumentFileController, AdminPanelProvider). This deliberately departs from the Phase 9 rule that no screen renders a signed link (D-10 of Phase 9, T-09-18) for exactly one case, the inline preview of a non-image file; the docblocks of `DocumentUrl`, `DocumentActions` and `RendersTaskCommentThread` are rewritten to name that one exception and why (owner decision of Phase 17). Residual, accepted with the owner decision: a page left open longer than `kokpit.documents.signed_url_ttl_seconds` (120 s) holds an expired PDF link that answers 403 in the new tab until the list renders again; it is listed for the end-of-phase check. `download()` is unchanged (an attachment never replaces the page). The UI-SPEC popup-blocked toast is not built: a real link click with target _blank is never blocked by a popup blocker.
- R-17-02-4 (lightbox view): new `resources/views/filament/documents/lightbox.blade.php`: a wrapper with 1rem padding and Alpine `x-data="{ loaded: false, failed: false }"`; a centred `<x-filament::loading-indicator>` shown while neither loaded nor failed; `<img x-ref="image" src="{{ $src }}" alt="{{ $name }}" style="display:block;margin:0 auto;max-width:100%;max-height:80vh;object-fit:contain;">` with `x-on:load="loaded = true"`, `x-on:error="failed = true"`, hidden when failed, and an `x-init` that settles both flags from `$refs.image.complete` and `naturalWidth` (a cached image fires `load` before Alpine starts); a `<p>` with `{{ __('documents.errors.preview_failed') }}` shown only when failed. Escaped output only, inline styles only (no asset pipeline, UI-SPEC Design System).
