## Flagged assumptions

- **A-HYG-05 (unresolved, edge probe unclassified):** "Full history" means all refs present in the CI checkout (`fetch-depth: 0`: branches, tags and the PR merge ref). Refs that were never fetched (other forks, deleted remote branches) are out of scope. The shell `--history` mode does not diff merge commits (`git log -p` default), so content that exists only in a merge-conflict resolution is covered by `--all` (tree) and gitleaks, not by the shell history scan. The Zerops token rule format and non-`.zerops.app` Zerops hostnames are `[ASSUMED]` (research A2). The owner should confirm these limits are acceptable.

Canon referral (not minted as prohibitions): workflow script injection, privileged triggers and unpinned third-party actions are canon CI-security items, covered by zizmor/actionlint here and by `/gsd-secure-phase`.
