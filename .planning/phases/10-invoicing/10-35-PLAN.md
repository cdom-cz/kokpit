## Scope note

- Files: 6; tasks: 2. Estimate: 15k + 4k x 6 + 3k x 2 = 45k, rounded to 48k for the harness reads; factor 1, confidence low.
- Wave 6 next to plans 10-14, 10-15 and 10-16 (no shared file; see `coupling_justified`).
- The concurrency suite commits rows (no RefreshDatabase). Issued rows are guarded, so the issue test's cleanup disables the user triggers of the invoice tables inside one cleanup transaction (`ALTER TABLE ... DISABLE TRIGGER USER`, delete the rows of its own fictional client, `ENABLE TRIGGER USER`) and asserts afterwards that every guard trigger is enabled again; drafts are not guarded, so the reservation test unreserves and deletes normally. Global function and constant names carry the prefixes `invoiceIssue` and `invoiceReservation` (Pest files share one namespace).
- Numbers in assertions are composed from fragments; the scanner refuses 8-digit literals.
