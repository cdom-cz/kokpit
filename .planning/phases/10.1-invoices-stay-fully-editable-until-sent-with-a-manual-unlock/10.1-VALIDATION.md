# Phase 10.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution. Source: the Validation Architecture section of `10.1-RESEARCH.md`.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Pest 5 (+ pest-plugin-laravel), PHPStan |
| **Config file** | `phpunit.xml`, `tests/Pest.php` (exist) |
| **Quick run command** | `ddev exec vendor/bin/pest <touched test file>` |
| **Full suite command** | `ddev exec vendor/bin/pest` |
| **Estimated runtime** | ~300 seconds (full suite) |

All commands run inside DDEV; the host has no database.

---

## Sampling Rate

- **After every task commit:** the touched test file(s) via `ddev exec vendor/bin/pest <file>`
- **After every plan wave:** `ddev exec vendor/bin/pest tests/Feature/Invoicing tests/Feature/Schema tests/Feature/Payments tests/Isolation tests/Arch`
- **Before `/gsd-verify-work`:** full `ddev exec vendor/bin/pest` plus `ddev exec vendor/bin/phpstan analyse --no-progress --memory-limit=1G`, both green
- **Max feedback latency:** 300 seconds
