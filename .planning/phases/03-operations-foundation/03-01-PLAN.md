- Composer packages for the spike come only from the research Package Legitimacy Audit (spike-only rows: `dompdf/dompdf`, `spatie/laravel-pdf`, `spatie/browsershot`) plus `chillerlan/php-qrcode` (already in the application lock through Filament). - `zbarimg` is absent on the host; the QR is decoded with the reader built into chillerlan/php-qrcode v5 from a `pdftoppm` raster, so no extra tool is installed.
- Measurements inside a Zerops `php-nginx@8.5` container need a Zerops project (human). Runtime needs on Zerops are recorded from documentation and marked `[ASSUMED]`; the deploy plan's rehearsal checklist (03-18) carries the container check.

Runs in parallel with 03-02 (kanban spike). Neither plan touches application files or the DDEV project, so they cannot collide with each other or with the application plans that follow.

Fictional data only (`.claude/CLAUDE.md`): Czech pangram text, `Example s.r.o.`, company ID `12345678`, an IBAN computed at runtime from placeholder fragments. Run `scripts/check-sensitive.sh` on the record before committing; never bypass the hook.
