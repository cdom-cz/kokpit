<objective>
Make background work fail loudly: a shared job base with retries, backoff, timeout, the system context and an explicit idempotence declaration (D-10), and a final-failure path that always ends in failed_jobs plus a throttled Admin alert by synchronous e-mail and the Filament bell, independent of the queue (D-11).

Purpose: FND-09. CNB rates, PDFs, e-mails, Stripe payment links and webhooks in later phases all run as jobs; a silent failure there means an unsent invoice or an unrecorded payment. The job contract tests (architecture rule, after-commit dispatch, production queue guard) follow in plan 03-14.
Output: job base, attribute and middleware, alert notification, alerter and listener, the bell, alert thresholds, test probes and tests.
</objective>

Verified before planning (Laravel 13.35): queue attributes `#[Tries]`, `#[Backoff]`, `#[Timeout]` are read from the class and its parents and a child's own attribute wins; `Job::fail()` dispatches `JobFailed` once per final failure in a `finally`, for package jobs too; `Filament\Notifications\Notification::sendToDatabase()` would queue a queueable notification, hence an own non-queueable notification class with a Filament-format `toDatabase()` and `Notification::sendNow`. `retry_after` on the redis connection is 90 (above the 60 s timeout).
