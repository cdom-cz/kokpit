Rulings made in this plan (recorded):
- R-18-06-1 (callout node, A1 following the researcher): `final class Callout extends AbstractBlock` with `public readonly string $type` (one of NOTE, TIP, IMPORTANT, WARNING, CAUTION, upper case). `final class CalloutExtension implements ExtensionInterface` with `__construct(private readonly Closure $translate)`; `register()` adds a `DocumentParsedEvent` listener and `CalloutRenderer` for `Callout`. The listener walks only the direct children of the document: a `BlockQuote` whose first child is a `Paragraph` whose first child is a `Text` whose literal matches `^\[!(NOTE|TIP|IMPORTANT|WARNING|CAUTION)\]$` case-insensitively, followed by a line break node or nothing, becomes a `Callout`: the marker and the following line break are removed, an emptied paragraph is detached, the remaining children are moved into the callout, and the block quote is replaced. A marker followed by text on the same line, an unknown type and any block quote that is not a direct child of the document stay block quotes. `KnowledgeMarkdown` registers `new CalloutExtension($this->translate)` next to the other extensions.
- R-18-06-2 (callout markup): `final class CalloutRenderer implements NodeRendererInterface` with `__construct(private readonly Closure $translate)` renders a `div` with classes `kokpit-callout kokpit-callout--{type in lower case}` holding a `p.kokpit-callout__label` with translate('callouts.{type in lower case}') and then the rendered children. The sanitiser config of 18-03 already allows `div[class]` and `p[class]`; no other element or attribute is added.
- R-18-06-3 (assets): `KnowledgeServiceProvider::boot()` calls `FilamentAsset::register([Css::make('kokpit-prose', resource_path('css/kokpit-prose.css')), Js::make('knowledge-copy', resource_path('js/knowledge-copy.js'))])` (package `app`; published to `public/css/app/kokpit-prose.css` and `public/js/app/knowledge-copy.js` by `filament:assets`, which `composer install` runs through `filament:upgrade`). No Vite, no Tailwind build, no Alpine component.
- R-18-06-4 (copy script): `resources/js/knowledge-copy.js` is one IIFE that returns early when `window.kokpitKnowledgeCopyBound` is set and sets it otherwise, then adds one `click` listener on `document`: the target's closest `[data-kokpit-copy]` button, its closest `.kokpit-code`, that block's `pre code` element; the text is that element's `textContent`; the label element is the button's `.kokpit-code__copy-label`, whose first label is kept in `button.dataset.labelDefault`. Success of `navigator.clipboard.writeText(text)`: label text set through `textContent` to `button.dataset.labelCopied`, `button.dataset.state = 'copied'`, restored after 2000 ms. Missing Clipboard API or a rejected promise: label set to `button.dataset.labelFailed`, `data-state` `failed`, the code element's text selected through `document.createRange()` and `window.getSelection()`, restored after 2000 ms. The script only reads text and data attributes and only assigns `textContent` and `dataset`; it never reads or writes markup, never evaluates strings and depends on no attribute an author can write (raw HTML is escaped by the renderer). The delegated listener survives Livewire morphs and SPA navigation.
- R-18-06-5 (stylesheet, UI-SPEC values): every selector starts with `.kokpit-prose` or `.dark .kokpit-prose`. Wrapper: max-width 48rem, body text 16px weight 400 line-height 1.5, `overflow-wrap: anywhere`; h1 28px, h2 20px, h3 to h6 16px, all weight 600 line-height 1.2; labels 14px weight 600; emphasis `strong` weight 600; no other size or weight. Spacing from the 4/8/16/24/32 px scale (block gap 24px, paragraph 16px, 32px above h1 and h2). Links `var(--primary-600)` (dark `var(--primary-400)`), underlined. Tables `display: block; overflow-x: auto`, 1px `var(--gray-200)` borders, header cells weight 600 on `var(--gray-50)`, cell padding 8px 16px. Task items without bullets, the checkbox before the text. `.kokpit-sr-only` visually hidden. Block quote 4px `var(--gray-300)` left border, 16px left padding. Callouts: 4px left border and an about 10% tint (`color-mix` with transparent) of `var(--info-600)` (note), `var(--success-600)` (tip), `var(--gray-600)` light and `var(--gray-400)` dark (important), `var(--warning-600)` (warning), `var(--danger-600)` (caution); the label carries the Heroicons outline icon of its type (information-circle, light-bulb, exclamation-circle, exclamation-triangle, shield-exclamation) drawn through `mask-image` with an inline SVG data URI (strokes written as the keyword `black`, never a hex value, so the hex rule below holds) and 4px gap; label text never lighter than gray-700 (light) or gray-200 (dark). Code block: 1px `var(--gray-200)` border (dark `var(--gray-700)`), 8px radius, header strip `var(--gray-200)` (dark `var(--gray-800)`) with padding 8px 16px, language label left in 14px weight 600 muted, Copy button right in the Filament extra-small gray button look with the clipboard icon (check icon for `data-state="copied"`) through `mask-image` and a visible focus ring in `var(--primary-600)`; `pre` padding 16px, `overflow-x: auto`, no wrapping, background `var(--gray-100)` (dark `var(--gray-900)`); code 14px `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`. Token colours through scoped custom properties: text `var(--gray-900)` / `var(--gray-200)`; comment (`hl-comment`) `var(--gray-600)` / `var(--gray-400)`; keyword (`hl-keyword`) `#6d28d9` / `#c4b5fd` (Filament has no violet variable; these two are the only hex literals of the file); string (`hl-value`) `var(--success-700)` / `var(--success-300)`; number and constant (`hl-number`, `hl-literal`) `var(--warning-700)` / `var(--warning-300)`; function and tag (`hl-property`, `hl-type`, `hl-attribute`, `hl-generic`) `var(--info-700)` / `var(--info-300)`; every other `hl-*` class keeps the text colour. `.kokpit-prose__plain` uses `white-space: pre-wrap`.
