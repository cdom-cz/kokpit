## Scope note

- Files: 4 planned (plus any production file an ordered amendment touches, recorded in the SUMMARY); tasks: 3. Estimate: about 20k for the sheet, 5k for the checkpoint, 20k for applying a decision; factor 1, confidence low.
- Wave 5, after every audit plan, so the owner reviews all findings at once.
- `autonomous: false`: Task 2 is a blocking decision checkpoint without `auto_select`. It is a `checkpoint:decision`, not a `checkpoint:human-verify`, so `workflow.human_verify_mode = end-of-phase` does not suppress it.
- Reversibility: the decision changes test declarations and, at most, small access rules; reversible. The checkpoint exists because only the owner can specify the matrix (D-02), not because of a one-way door.
