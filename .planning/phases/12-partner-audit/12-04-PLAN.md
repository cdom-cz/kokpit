Rulings made in this plan (recorded):
- R-12-04-1 (ability rows): `partnerAbilities()` returns `model class => ['class' => [ability => bool], 'records' => [ability => [state => bool]]]`; `abilityRows()` flattens it to `"Model ability state" => [model, ability, state]` for the dataset (plain arrays, research Pitfall 4). `adminOnlyModels()` returns `model class => reason`.
- R-12-04-2 (field surfaces): `partnerFields()` returns `'{ShortClass}.{table|infolist|form|filters}' => list<string>`; the runtime names are read as the existing tests do: table columns `array_keys(Livewire::test($listPage)->instance()->getTable()->getColumns())`, filters `array_keys(...->getTable()->getFilters())`, infolist `$resource::infolist(Schema::make($page))->getFlatComponents()` mapped to `getName()`, resource form `$resource::form(Schema::make($createPage))->getFlatFields(withHidden: true)` keys, relation manager tables and forms through `Livewire::test($manager, ['ownerRecord' => $own, 'pageClass' => $viewPage])->instance()`, widget tables through `Livewire::test($widget)->instance()->getTable()`, the profile form through the mounted EditProfile page's form schema. Verify each Filament 5 method in vendor/filament before use (research A3) and record the calls used in the SUMMARY.
- R-12-04-3 (forbidden pattern): `const string FORBIDDEN_FIELD_PATTERN` is a case-insensitive regular expression over the words rate, price, estimate, billing, billable, internal, cnb, czk, exchange, payment, source, cost, budget, hours, duration, unbilled; `fieldExceptions()` returns `surface name => reason` for an allowed name that matches it (for example the unit price of an own issued invoice item, IN-09).
