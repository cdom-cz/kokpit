Rulings made in this plan (recorded):
- R-13-04-1 (escaping): every value typed by an Admin, a Partner or produced at runtime that goes into a Markdown line or heading passes through `MailText::escapeMarkdown()`: the invitee name and the client name of the invitation, the title (greeting) and every body line of an operational alert. Action URLs and fixed translation texts are not escaped; subjects stay plain text (a header is never rendered as markup). The text part reads without escapes because the published text layout of plan 13-01 reverses them.
- R-13-04-2 (invitation): Czech copy under `kokpit.invitations.mail.*` reviewed: formal address without a gendered past participle (the current intro mixes a singular greeting with "byli jste pozváni"), the invitee name in the greeting, the client named in the intro, the subject naming the supplier (`:supplier`, from `MailBrand::current()->name`, plain text), the button "Přijmout pozvánku", the expiry line and the outro; a salutation of two lines, `mail_layout.regards` and the supplier name (escaped), set with `->salutation()` (the published view of plan 13-01 prints each line and joins them with a line break). Scalars-only constructor, `ShouldQueue` and `afterCommit()` stay.
- R-13-04-3 (password reset, research Pattern 6 and Pitfall 9): `App\Domain\Identity\Notifications\ResetPasswordNotification` is a `final` subclass of `Filament\Auth\Notifications\ResetPassword` (so it stays queued and keeps Filament's `public string $url` and `resetUrl()`), overriding only `protected function buildMailMessage($url)` with `kokpit.password_reset.mail.*`: subject, intro, action, expiry (`:count` = `config('auth.passwords.'.config('auth.defaults.passwords').'.expire')`, the broker the panel uses because it names none; read from config, never from the current panel, because a queued worker has none) and outro; no greeting set (the default greeting of plan 13-01 applies), no salutation. Suggested copy: subject `Obnovení hesla`, intro `obdrželi jsme žádost o obnovení hesla k vašemu účtu.`, action `Nastavit nové heslo`, expiry `Odkaz platí :count minut.`, outro `Pokud jste o obnovení nežádali, nic nedělejte: vaše heslo zůstává beze změny.`. The two call sites import the subclass instead of Filament's class and keep `app(ResetPasswordNotification::class, ['token' => $token])` and `$notification->url = Filament::getResetPasswordUrl($token, $user)` unchanged; their docblocks say the notification is Kokpit's. | Boundary | Description |
|----------|-------------|
| Admin-typed invitee and client names -> e-mail to an outside person | free text in a Markdown heading and line |
