Rulings made in this plan (recorded):
- R11-01-1 (D-18, research Standard Stack): the official `stripe/stripe-php` SDK (MIT, `^22.0`) is used, not direct HTTP: it carries the form encoding of nested parameters, the idempotency header and `WebhookSignature::verifyHeader`, which plan 11-04 needs. It is confined to `app/Domain/Payments/Stripe/`; no other directory imports a `Stripe\` class.
- R11-01-2 (Pitfall 7, discretion "Stripe API version pinning"): `StripeApiGateway::API_VERSION = '2026-09-30.endive'` is passed to the client as the `stripe_version`, so a later SDK update cannot move the API version silently; the client timeout is 20 s (below the 60 s job timeout), the connect timeout 5 s, `max_network_retries` 1.
- R11-01-3 (D-09, research Security V7): failure classes are the constants of `StripeGatewayFailure` (`not_configured`, `authentication`, `invalid_request`, `rate_limited`, `connection`, `api_error`, `idempotency`, `unsupported_currency`); `isRetryable()` is true only for `connection` and `rate_limited`. A 5xx (`api_error`) is not retryable because Stripe replays a stored 500 for the same idempotency key (Pitfall 7). The exception message is the fixed text `Stripe request failed: <class>`; the SDK exception stays the previous exception only.
- R11-01-4 (research Pitfall 8, Assumption A6): `PaymentLinkRequest` refuses the currencies ISK and UGX with the class `unsupported_currency` before any call (Stripe's two-decimal convention for them differs from the ISO exponent); a remaining amount below Stripe's minimum comes back from Stripe as `invalid_request`.
- R11-01-5 (A10): environment keys `STRIPE_SECRET` and `STRIPE_WEBHOOK_SECRET`, config `services.stripe.secret`, `services.stripe.webhook_secret`; `StripeConfig::isConfigured()` is true only when both are non-empty strings (UI-SPEC U-4: a link is created only when Stripe is fully configured).
- R11-01-6 (Pitfall 14, repository hygiene): no test, fixture, doc or commit message contains a Stripe-shaped value; the fake and `StripeTestConfig` assemble every key, link id and URL at runtime from a prefix fragment, an underscore and `Str::random()`.

Package legitimacy (research "Package Legitimacy Audit"): the verdict for `stripe/stripe-php` could not be machine-checked for Composer ("not machine-checked"), so it is treated as [ASSUMED] and the install waits for the blocking human checkpoint of Task 1.
