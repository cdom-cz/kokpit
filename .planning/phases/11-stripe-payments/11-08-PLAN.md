Rulings made in this plan (recorded):
- R11-08-1 (research Pattern 7, A3 resolved): the page is a controller with a standalone Blade document, not a Livewire page and not the Filament simple layout (that layout renders Livewire scripts and a CSRF meta tag, which need the session this route deliberately does not start). The view loads the panel's assets with `@filamentStyles`, `filament()->getTheme()->getHtml()` and `filament()->getFontHtml()` under the route middleware `Filament\Http\Middleware\SetUpPanel:admin`, and uses only anonymous Blade components (`x-filament::icon`, `x-filament::button` with `tag="a"`) and inline styles from the UI-SPEC spacing and type scale (F-2, F-11). No script. The path stays `/pay/{token}` as fixed by `PayUrl` (plan 11-03).
- R11-08-2 (U-2, D-02): `PayPageState::resolve(string $token): array{outcome: PayPageOutcome, number: ?string, language: ?InvoiceLanguage, url: ?string}`. Order: a token failing `PayToken::isWellFormed()` is Invalid before any query; then, as system, the `invoice_admin` row by `pay_token` (none: Invalid), its invoice (not an issued invoice or proforma: Invalid); a cancelled document is Cancelled; remaining 0 is Paid; a live link in state active whose `stripe_url` passes `StripeUrl::isAllowed()` is Redirect with that URL; otherwise Preparing (pending, failed, deactivated, partially paid, or no link).
- R11-08-3 (Pattern 7, Pitfall 10): `PayPageController::__invoke(string $token)` answers Redirect with `302` and every other outcome with `200` and the view; headers `Cache-Control: no-store`, `X-Robots-Tag: noindex, nofollow` on both, `Referrer-Policy: no-referrer` through `SetNoReferrerPolicy`. The invalid view is rendered from constants only, so every invalid cause gives the same bytes.
- R11-08-4: `StripeUrl::isAllowed(?string $url): bool` is true only for `https` with the host `stripe.com` or a host ending in `.stripe.com`, no user info and no port.
- R11-08-5 (Pattern 7): `PaymentsServiceProvider::boot()` registers `RateLimiter::for('pay-page', 30 per minute by IP)` and `RateLimiter::for('stripe-webhook', 600 per minute by IP)` (Stripe retries a 429). `routes/public.php`: `GET /pay/{token}` named `pay.show` with `[SetNoReferrerPolicy::class, 'Filament\Http\Middleware\SetUpPanel:admin', 'throttle:pay-page']`, and the webhook route gains `throttle:stripe-webhook`.
- R11-08-6 (UI-SPEC Panel configuration, SPA): `AdminPanelProvider` `spaUrlExceptions` gains `'*/pay/*'` next to `'*/admin/files/*'`.
