Rulings made in this plan (recorded):
- R-15-09-1 (data): `CashReceiptPdfData::fromReceipt(CashReceipt $receipt): self` builds from the row only: header (`title`, number), dates (`issued_on`, `received_on` as `j. n. Y` for cs and `Y-m-d` for en), parties via `PdfParts::party()` of 15-03 (received from = customer snapshot, received by = supplier snapshot with the not-VAT-payer note), amount via `Money::format(language)`, purpose, the paid document number from the receipt's own frozen `document_number` column (15-02; no read of invoices), the issuer line with the supplier name, signature and logo images through `PdfParts::image()` and palette from the appearance snapshot, the footer through `PdfParts::footer()`, `cancelled` (null or the cancelled date text), page template. Throws `LogicException` for a missing snapshot and `UnexpectedValueException` for a changed image, like `InvoicePdfData`.
- R-15-09-2 (renderer and view): `CashReceiptPdf::render(CashReceipt): string`, `html(CashReceipt): string`, `fileName(CashReceipt): string` (number reduced with `preg_replace('/[^A-Za-z0-9._-]+/', '-', ...)`, `cash_receipt_pdf.file_name` = `prijmovy-doklad-:number.pdf` / `cash-receipt-:number.pdf`). Rendering goes through `ClosedDompdf::render()` of 15-03 with `InvoicePageDecoration` as the page script. View `resources/views/pdf/cash-receipt.blade.php` (inside the Dompdf chroot) prints with `{{ }}` only, one A4 page, fonts through `ClosedDompdf::fontUrl()`. A cancelled receipt shows a full-width band `cash_receipt_pdf.cancelled` ("STORNO - doklad zrušen :date" / "CANCELLED on :date").
- R-15-09-3 (lang): `lang/{cs,en}/cash_receipt_pdf.php` gain: `title` ("Příjmový pokladní doklad" / "Cash receipt"), `number`, `issued_on` ("Datum vystavení" / "Date of issue"), `received_on` ("Datum přijetí hotovosti" / "Date cash received"), `received_from` ("Přijato od" / "Received from"), `received_by` ("Příjemce" / "Received by"), `amount` ("Přijatá částka" / "Amount received"), `purpose_label` ("Účel platby" / "Purpose"), `document` ("Hrazený doklad" / "Document paid"), `issuer` ("Doklad vystaven elektronicky: :name" / "Issued electronically by :name"), `company_id`, `vat_id`, `not_vat_payer`, `cancelled`, `page`, `file_name`. No real names or numbers.
- R-15-09-4 (store/replace): `StoreCashReceiptPdf::handle(User $actor, CashReceipt $locked): Document`: `LogicException` outside a transaction; render first (a failing render changes nothing); lock the receipt row; when a linked file exists, delete it through `DeleteDocument::handle($actor, $old, confirmedIssuedPdf: true)` (the FK clears the link); store the new bytes through `StoreGeneratedDocument::handle($actor, $locked, $bytes, $fileName)`; link `pdf_document_id`. Any non-refusal failure becomes `RuntimeException(__('documents.actions.delete_issued_pdf.regenerate_failed'))` with the cause chained (as `ReplaceIssuedPdf`). Callers: `IssueCashReceipt` (now), cancel (15-12), edit and regenerate (15-13). The protection of the stored file against any other delete path is 15-12.
- R-15-09-5 (owner type): `DocumentOwnerType::CashReceipt = 'cash_receipt'`, `isShareable()` false (the `documents_visible_owner_check` list stays project, task, task_comment), label `enums.document_owner_type.cash_receipt` "Příjmový doklad"; `DocumentOwnerResolver` resolves a receipt to its client, no project, not shareable, under a shared lock as system.
