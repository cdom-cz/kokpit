Rulings made in this plan (recorded):
- R-14-03-1 (service): `App\Domain\Invoicing\Support\InvoiceCurrencies` is a `final readonly class` with `public static function choices(?Client $client, ?string $current): array` returning `list<string>`: the distinct `currency` values of `ExchangeRate` (one query, `ExchangeRate::query()->distinct()->pluck('currency')`, all dates: a currency CNB ever published), the `currency` of every account in `app(BankAccountSettings::class)->accounts`, `$client?->currency`, `$current`, and `'CZK'` (CNB publishes no CZK row, CZK needs no rate; assumption A7); upper-cased, kept only when `Money::isKnownCurrency()` accepts it, de-duplicated and sorted with `sort()` (the order the editors already use). It reads `ExchangeRate`, which denies Partners, so it is called only from Admin pages and Admin Actions; a Partner context gets the accounts, client, current and CZK only, which is never shown to a Partner anyway.
- R-14-03-2 (call sites): `CreateDraftAction::currencyOptions(?string $clientId)` returns `array_combine($codes, $codes)` of `InvoiceCurrencies::choices(self::client($clientId), null)`; `IssuedDocumentRules::currencyChoices(Invoice $invoice)` returns `InvoiceCurrencies::choices($invoice->client, $invoice->currency)`, so `EditInvoice::currencyOptions()` (draft and issued editor) and the issued write path `UpdateIssuedDocument::currencyChange()` follow without an edit here. Both docblocks are rewritten to D-07. `CreateDraft` and `UpdateDraft` keep accepting any code `Money::isKnownCurrency()` knows (research Pattern 3: only the issued path enforces the list).
- R-14-03-3 (blockers unchanged): a listed currency without a CNB list on the issue date is already the `cnb_missing` blocker of `IssueChecks` and the `cnb_missing` refusal of the issued currency change; no new check. A currency without a bank account is still refused by the issued currency change until plan 14-09 decouples the account; this plan changes only what is offered.
