Rulings made in this plan (recorded):
- R-12-01-1 (route key): the key of a route is its name when it has one; otherwise `METHOD /uri`, where METHOD is the first method other than HEAD and the uri has its Livewire prefix replaced by the regular expression `#^livewire-[0-9a-f]{8}#` -> `livewire-{hash}` (the prefix is derived from APP_KEY in vendor/livewire/livewire/src/Mechanisms/HandleRequests/EndpointResolver.php, so it differs per machine). D-06 says "route name"; eight routes have no name and vendor routes cannot be renamed, so the fallback keeps D-06 for every named route. Presented to the owner in plan 12-08 (Open Question 3).
- R-12-01-2 (auth recogniser): a route is authenticated when one of its resolved middleware strings (from `app('router')->gatherRouteMiddleware($route)`, never `$route->gatherMiddleware()`, which leaves aliases unresolved) starts with `Filament\Http\Middleware\Authenticate`, `Illuminate\Auth\Middleware\Authenticate` (the `:sanctum` form included) or `Laravel\Horizon\Http\Middleware\Authenticate`.
- R-12-01-3 (closed list): a deliberately dead route is declared in `RouteRules::closedRoutes()` with its expected status (403, 404 or 410) and a reason, instead of widening the D-05 status set. Initially the two Filament action routes `filament.exports.download` and `filament.imports.failed-rows.download` (status 404; Kokpit uses no Filament export or import action and the tables do not exist). Plan 12-02 makes them answer 404 and proves it.
- R-12-01-4 (CI shape): `composer test` and the CI `Pest` step run `vendor/bin/pest --exclude-testsuite=Audit`; the new script `composer partner-audit` and the new CI step `Partner audit` run `vendor/bin/pest --testsuite=Audit`; `composer ci` runs `@test`, `@partner-audit`, `@lint`, `@stan`, `@check-licenses` in that order. The script is not named `audit` because `composer audit` is Composer's own command, which the dependencies job already runs. A plain `vendor/bin/pest` (the GSD test command) still runs every suite. Presented to the owner in plan 12-08 (Open Question 4).
