<objective>
Add the default currency and the default hourly rate to the settings page through a new no-rounding `Money::fromMajor`, validated in the form and again at the data layer (D-02; FND-07 default rate and currency).

Purpose: rate resolution (Phase 6) and invoicing (Phase 10) start from these values; a silently rounded rate would corrupt every later amount.
Output: Money additions, `MoneySettingsCast`, `DefaultsSettings` with its migration, the defaults tab, unit and feature tests.
</objective>
