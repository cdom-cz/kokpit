Decisions made in this plan (recorded):
- The stats widget lives under `ExchangeRateResource/Widgets/`, registered as a header widget of the list page, so the panel does not discover it as a dashboard widget (the dashboard widget set is pinned by `PanelAccessTest`).
- The Czech currency name comes from ICU through ext-intl (`ResourceBundle::create('cs', 'ICUDATA-curr')`, entry `Currencies.<code>.1`); a code without a name shows the code only.
- Download outcome mapping: `skipped` -> already stored; `valid_for` equal to today -> stored; `valid_for` before today -> CNB has no newer list yet (body names that date); `CnbDownloadFailed` -> danger with the copy's fallback sentence, never the reason class or status. The manual run is never gated by the working-day calendar and never alerts.
- Test fixtures store no older lists with working-day gaps, so the gap self-heal of plan 08-17 (scheduled command only) never interferes.

Fictional data only: CNB answers in tests come from `CnbFixtures` with invented rates. Run `scripts/check-sensitive.sh` before every commit; never bypass the hook.
