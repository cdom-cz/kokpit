<objective>
Complete the generic rule set of the sensitive-content checker so that every D-02 category fails with file and line: e-mails, 8-digit company IDs, IBANs, Czech accounts, public IPv4s, hosting hostnames and personal home paths. Key prefixes already exist from plan 01-01. Exemptions go through a narrow, reviewed allowlist.

Purpose: roadmap success criterion 1 requires every category to block a staged change while clean changes pass. False positives must stay rare enough that nobody is tempted to bypass the hook.
Output: rule families in `scripts/lib/scan.awk`, `scripts/sensitive-allowlist.txt`, a test case per rule, and a Docker helper that proves mawk compatibility.
</objective>
