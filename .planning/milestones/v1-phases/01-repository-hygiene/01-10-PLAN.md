- case-insensitive hosting-host matching flags the upper-case example bucket host quoted in `01-REVIEW.md` (the WR-03 reproduction). That file is an immutable phase record, so the exemption is one exact-path, exact-value allowlist entry (Task 3).
- Narrowing the invoice exemption to `^20(2[5-9]|3[0-9])...` would flag a version string quoted in the immutable 01-01 plan and 01-02 summary. `^20[23][0-9]{5}$` keeps every planning document clean, so it is the chosen narrowing.

gitleaks facts, verified at planning time with gitleaks 8.30.1 and probe configs:
- The default ruleset that `[extend] useDefault = true` pulls in has a global allowlist. Its path-shaped regexes drop any secret that is a path starting with `/home/` followed by more characters, and any secret like `/Users/<a>/<b>`. The current `kokpit-home-path` rule therefore never reports a `/home/<name>/` path at all; a probe with the current config and a trailing-slash `/home/` path exited 0. This is a second-layer gap beyond CR-03.
- The fix is to capture only the name segment as the secret (`secretGroup = 1` on the name) and to anchor the rule's placeholder allowlist on the name. With that probe config, all four bare, quoted, `&&` and line-start shapes were reported (the line-start one at its own line), and the placeholders, the URL path and the relative path were not. The Windows probe rule reported both forms and skipped `Public`. The `kokpit-ico-like` probe reported the IČ, IC, IČO and ico lines and skipped the 12345678 placeholder.
- Go RE2 has no lookbehind, and its `\b` is ASCII-only, so `ič\b` never matches before `:`. A left boundary written as a consumed character class would start a line-initial match on the previous line's newline. The patterns therefore use `(?m)` with `^` and a class that excludes CR and LF, so a match at the start of a line starts on that line.

Plan 01-08 added test-gitleaks.sh cases (f) to (i) and the `GLK_LOG_OPTS` variable; this plan continues with (j). The new test-check-sensitive.sh cases use the prefixes H (home path), W (Windows) and B (boundaries) so they cannot collide with the existing letters (a) to (z).
