Decisions carried in (locked): D-10 (every download and preview through an app route that checks the policy, then a short-lived signed URL or streaming; no public bucket URL; TTL short, value in `config/kokpit.php`; images and PDF inline, everything else as attachment), D-06 (`X-Content-Type-Options: nosniff`, no inline rendering except images and PDF).

Decisions made in this plan (recorded):
- Streaming through the app, not a redirect to `Storage::temporaryUrl()`: the DDEV bucket endpoint `rustfs:9000` is not browser-reachable and an S3 response cannot carry `nosniff` (research Alternatives, Pitfall 2).
- Route path `/admin/files/documents/{document}`, name `filament.admin.files.document` (research A9: the name is verified with `route:list` in Task 1); `files` is a path prefix that no resource slug uses, so `spaUrlExceptions(['*/admin/files/*'])` takes all file routes out of SPA navigation (vendor ViewManager::hasSpaMode).
- Screens never render a signed URL into HTML: an action computes it at click time and redirects (TTL 120 s would expire on an open page). Preview opens in the same tab.
- The Partner `view` grant is added in plan 09-08; until then a Partner's own visible file answers 403 here, a foreign or hidden one 404.
