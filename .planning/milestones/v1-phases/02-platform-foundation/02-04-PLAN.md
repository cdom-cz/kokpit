<objective>
Bring every remaining package table named in roadmap success criterion 3 under the conventions from 02-03: Sanctum tokens, database notifications, webhook calls, media, tags and the activity log. Each gets an edited published migration, a registered `HasUuids` subclass and a morph alias, and is exercised once through the package's own public API so registration mistakes surface (RESEARCH Pitfall 3).

Purpose: FND-02 and FND-03 for package tables. Without the subclass the package silently stores null or integer-cast keys; without the alias it stores class names.
Output: six edited migrations, five subclasses, four package configs, morph aliases, rules R8 (complete) and R9, `PackageModelsTest`.
</objective>
