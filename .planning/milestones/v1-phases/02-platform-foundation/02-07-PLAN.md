<objective>
Establish the database-enforced integrity pattern later phases reuse for issued invoices and billed time entries: a generic immutability trigger function, a PHP helper that emits its trigger DDL safely, the companion constraint shapes (FK, CHECK, partial unique index), and a raw-SQL test helper, all proven on a pilot table that exists only inside the tests.

Purpose: FND-12 and roadmap success criterion 3 (pilot trigger, CHECK and partial index proven by raw-SQL tests). Application-level guards are bypassed by raw SQL, package code and tinker (RESEARCH "Don't Hand-Roll"); the database is the only writer-independent place.
Output: guard function migration, `Immutability` helper, `RawSql` helper, pilot and unit tests.
</objective>
