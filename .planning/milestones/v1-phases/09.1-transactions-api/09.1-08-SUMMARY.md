## Accomplishments

- `TransactionApiFlowTest` discovers the expense categories, picks a child of the Software root, books a CZK, an own-rate EUR (25.125) and a bank-figure USD (116000) expense in one batch with a client UUID and the project key `FLOW`, finds the EUR row with `filter[czk_source]=custom` and the date range (czk_minor 251250, project UUID resolved from the key), corrects its amount (502500, still `custom`), returns it to the CNB rate with both nulls (504000 at the stored list of 2026-10-09, source `cnb`), deletes the USD row (204) and gets 404 afterwards.
- The same file proves the refusals over every route shape of the phase (403 for a time-only token, 401 for a Partner token and for no token, nothing written) and that every write of the journey is logged with `source = api` and the Admin as causer.
- CONTRIBUTING carries a "Phase 9.1 (Transactions API)" hand-over (eight routes, four abilities, the `custom` source and the sticky own-rate rule, the batch limit, `CONFLICT_METHODS`, idempotency) and the Phase 10 hand-overs (6) to (8): re-read the finance Actions as changed by 9.1, plan 10-19 adds one API test per endpoint for the payment-income refusal and adds `'PATCH'` to `CONFLICT_METHODS` only if that refusal becomes a 409, and a payment income is not booked with the `custom` source unless Phase 10 decides so.
- `09.1-VALIDATION.md` is approved (`nyquist_compliant: true`, `wave_0_complete: true`), every row names the plan that created or extended its file, and the measured 500-item batch duration (0.83 to 0.87 s, plan 09.1-07) is recorded in the approval line.
