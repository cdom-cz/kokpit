## Accomplishments

- A token created through the create modal with `finance:read` and `finance:write` stores exactly those two abilities, reads `GET /api/v1/transactions/{id}` with 200 and gets 403 on `GET /api/v1/time-entries`.
- The create modal is pinned to offer the four abilities in order with their Czech labels and descriptions, read from the CheckboxList component.
- `Čtení financí` and `Zápis financí` join the strings no Partner page may show.
- `config/scribe.php`: the description names finance transactions and categories; the intro lists four abilities with the endpoints each opens and the 403 between time-only and finance-only tokens; "Lists and pagination" carries the transaction order (newest first by transaction date, ties by id); "Formats and errors" explains minor units with an ISO 4217 currency, the `YYYY-MM-DD` date, the decimal-string rate and the four `czk_source` values (`identity`, `cnb`, `manual`, `custom`); the authentication hint names all four abilities. Every sentence the limit regexes read is unchanged.
- `CONTRIBUTING.md`: "REST API" describes one group per ability with the matching limit and never a finance route in a time group; "API documentation" pins every route without a number and names `TransactionExamples` next to `ApiExamples` and `LookupExamples`. This also removes the stale "twelve routes" and "exactly two route groups" sentences.
