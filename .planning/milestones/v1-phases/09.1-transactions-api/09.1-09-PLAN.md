<objective>
Close the one blocking gap of 09.1-VERIFICATION.md (CR-01) and the warning WR-01 in the API mapping class, guard the finance:write refusal walk against vacuity (WR-04), and record the three as fixed.

1. CR-01 (D-06 option b, owner decision A1): `TransactionPayload::cleared()` stops forcing `czk_manual = false` when a PATCH names `exchange_rate: null` on a custom row and sends a `czk_amount_minor` value; it then returns only `['exchange_rate' => null]`, so the typed figure makes the row manual. Regression tests prove it with a CNB list, without a CNB list for the day, and with a changed currency that has no CNB rows. The PATCH docs of `exchange_rate` name the combination.
2. WR-01: a JSON boolean no longer passes the `integer` rule of `amount_minor`, `czk_amount_minor` or `exchange_unit_amount`; it is refused with 422 under the field and the panel message, on create, update and (through the shared rules) batch items. Tests on create, update and a batch item.
3. WR-04: `expect($routes)->not->toBeEmpty()` in the finance:write refusal test and the stale comment removed; then the bookkeeping (disposition and validation rows) and the phase gate.

Explicit deferrals (stay `open` in 09.1-REVIEW-DISPOSITION.md, no task here): WR-02 (batch idempotency stale-lock window), WR-03 (pre-lock snapshot and model class in a race 404), IN-01 (Scribe intro wording of `manual`), IN-02 (frozen manual figure not documented), IN-03 (422 before 404 on PATCH). `TransactionPayload::major()` is left as it is: once booleans fail the rule, every value that passes `integer` is numeric, so no request reaches it with a non-numeric value.

Purpose: a bank CZK figure sent by an importer is never silently replaced by the CNB figure, and a boolean can never re-denominate or drop an amount; the phase can go back to the verifier.
Output: the two fixes in `TransactionPayload`, one docs clause, six new feature tests in `TransactionWriteTest.php` plus one guard line in `TransactionAbilityTest.php`, the disposition and validation bookkeeping, a green gate.
</objective>
