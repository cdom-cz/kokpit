Decisions made in this plan (recorded):
- Research A11: the preference is a nullable boolean `users.time_panel_open` (null = default by viewport), written only through `SetTimePanelOpen` for the actor's own row. `users` is `NotPartnerScoped`; no Partner-readable table gains a column, so `PartnerSafeColumnsTest` is untouched.

- Day attribution: an entry belongs to the Prague day of its start (research A5), bucketed with UTC range predicates.
- Styles: a scoped `<style>` block in the panel view with a `min-width: 80rem` media query and only the UI-SPEC spacing tokens (research Pitfall 11, A8).

Fictional data only. Run `scripts/check-sensitive.sh` before every commit; never bypass the hook.
